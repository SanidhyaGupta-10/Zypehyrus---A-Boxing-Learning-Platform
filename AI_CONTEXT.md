## 🥊 Project Overview
- **Name:** AI Boxing Protocol / AI Boxing Guru
- **Stack:** Vanilla HTML, CSS (`style.css`), JavaScript. No frontend frameworks (no React, no Tailwind).
- **Architecture:** Client-side only. Data is persisted purely via `localStorage`. AI generation is handled client-side via fetch calls to Google Gemini API.
- **Design System:** Cyber-Athletic, Premium Dark Mode. Heavy use of glassmorphism (`backdrop-filter: blur`), neon accents (`var(--primary) : #e2ff3b`), and micro-animations (Pulse, Hover-Scale).

## 🗂 Routing / Main Files
- **`index.html` -> `constraints.html` -> `promise.html`**: Onboarding Flow. Collects user bio-metrics, goals, experience levels, and a final "Fighter's Promise". Saves to `localStorage` under `boxing_onboarding_data`.
- **`dashboard.html`**: The main HUD. Displays the "Today Challenge" which is dynamically generated. Features a **Weekly AI Debrief** on Sundays – a cinematic narrative summary of the week's training generated by Gemini.
- **`planner.html`**: The AI Strategic Roadmap. Generates a custom 7-day training plan using the Google Gemini API.
- **`protocol-start.html` & `protocol-session.html`**: Dedicated UI flow for executing AI-generated protocols from the Planner.
- **`training.html`**: Standard ("Daily Grind") dynamically generated workouts based on the user's level and available time, focusing on bodyweight exercises and boxing routines.
- **Detection Watcher:** Actively monitors for human presence (simulated). Triggers voice alerts if the user leaves the frame.
- **Slash Redirect Engine:** Cinematic red diagonal slash animation triggers on critical failures (e.g., person not detected for 5s), forcing a return to dashboard.
- **Personalized Coaching:** Voice engine now uses the fighter's `ring_name` for directional alerts and motivation.
- **Robust Recording:** Captures at 480p for optimized Gemini multimodal processing while maintaining high frame rates for velocity calculation.
- **`session-timer.html`**: The active workout execution screen (round timers, rep counters, interval progress).
- **`reflex-enhancer.html`**: Interactive click/tap mini-games ("Reaction Tap", "Combo Flash") to train hand-eye coordination.
- **`guru.html` & `technical-detail.html`**: The combat encyclopedia. Data stored in `techniques-data.js`.
- **`vision-analyser.html`**: Mockup for a future camera-based feedback system (the central "VIDEO" hex button).

## 🎥 AI Video Analyser — System Architecture (✅ BUILT — vision-analyser.html)

> This is the next major feature. `vision-analyser.html` will be refactored from a mockup into a **fully functional 3-Stage AI Coaching Engine** powered by **Gemini 1.5 Pro (Multimodal)**.

---

### 🧠 AI Role
- **AI Name:** "ZEPHYR Boxing Coach AI"
- **Model:** Gemini 1.5 Pro (multimodal — can read video + audio simultaneously)
- **Output Modes:** Markdown table (planner), TTS commands (drill), strict JSON (video analysis)

---

### ⚙️ Stage 1: Dynamic Planner Generation
- **Input:** User JSON from `boxing_onboarding_data` (Experience, Goal, Available Time, Injuries)
- **Output:** A Markdown Table → `Day | Pillar | Primary Exercise | Alternative | Sets/Reps`
- **Rules:** If Available Time < 30 mins → max 2 exercises/day. Randomized weekly so no two weeks are identical.

---

### 🎙️ Stage 2: Live Drill Coaching (TTS Engine)
- **Goal:** Generate short punch command strings for the browser's Text-to-Speech (`SpeechSynthesis`) API.
- **Commands:** `Jab`, `Cross`, `Hook`, `Uppercut`, `Duck`
- **Experience Scaling:** Beginners → single punches. Pros → 4-punch combos.
- **Calibration Script (first 10 sec):** `"Step into frame. Guard up. Chin down. 3, 2, 1... BOX!"`

---

### 📹 Stage 3: Multimodal Video Analyzer
- **Input:** An MP4 video containing the user's movements AND the AI coach's voice commands.
- **Gemini Task:** Temporal alignment — match audio command timestamp to user's punch extension timestamp.
- **Metrics Extracted:**
  - `reflex_time_ms` — delay between audio command and start of motion
  - `punch_velocity` — `'Slow'` / `'Snappy'` / `'Explosive'` from frame-by-frame wrist tracking
  - `guard_consistency` — % of time hands returned to face after punch
  - `posture_score` — 1–10 rating from the 10-second calibration window
  - `primary_technical_flaw` — one specific coach correction (e.g., "You are dropping your right hand when you jab")

---

### 📊 Required JSON Output Schema (Video Analysis)
```json
{
  "session_summary": {
    "posture_score": 0,
    "overall_reflex_rating": "Elite | Amateur | Novice",
    "primary_technical_flaw": "Description",
    "calibration_status": "Passed | Failed"
  },
  "drill_data": [
    {
      "command": "Jab",
      "command_timestamp_ms": 0,
      "reflex_time_ms": 0,
      "punch_speed_ms": 0,
      "form_notes": "e.g., Good snap, but elbow flared"
    }
  ],
  "coach_advice": "2-sentence motivational tip for next session."
}
```
> **CRITICAL:** Gemini must return ONLY this JSON — no conversational text. The app renders charts directly from the parsed response.

---

### 🔗 How it Stitches the App Together
- **Planner** feeds from `boxing_onboarding_data` onboarding JSON.
- **TTS Drill** tells the app exactly what words to send to the browser `SpeechSynthesis` engine — the audio gets recorded into the video.
- **Video Analyzer** uses multimodal Gemini to "listen" to that TTS audio + "watch" the user's hands simultaneously.
- **Charts** render directly from the JSON response (e.g., `reflex_time_ms: 240` → "Level Up" notification).
